# Excel Data Cleaner & Aggregator (実務特化型 Excelデータ自動クレンジング・集計パイプライン)

複数拠点や各担当者から集まる「表記揺れ・フォーマットの不揃いなExcel帳票」を一括自動検知・クレンジングし、統合データマスタおよび装飾付き集計サマリーレポートを瞬時に出力するPython自動化ツールです。

事務現場・経理・営業管理における「手作業でのコピペ統合・書式統一の手間（毎月数時間〜数十時間）」を完全自動化（処理時間0.1秒未満）します。

---

## 🌟 主な機能・解決できる課題

- **不揃いな列名の自動正規化:**
  - 各ファイルで異なるヘッダー（例：「売上日 / 取引日 / 販売日」「品名 / 商品名」「販売価格 / 単価」）を同一項目として自動マッピング。
- **泥臭い表記揺れの完全クレンジング:**
  - 金額・数量に含まれる不要記号（`¥`、`円`、`,`、前後の空白）や全角数字（`２` ➔ `2`）を半角数値型へ正規化。
  - バラバラな日付形式（`2026/09/01`、`2026-09-01`、`2026年9月2日`）を標準の `YYYY-MM-DD` 形式へ統一。
- **自動計算 & 拠点メタデータの付与:**
  - ファイル名から「拠点名」を自動判別して列追加し、`単価 × 数量 = 売上金額` を自動算出。
- **ビジネス仕様のExcelダッシュボード自動生成:**
  - `openpyxl` を駆使し、単なるCSVではなく「濃紺ヘッダー」「薄灰色グリッド」「通貨フォーマット（`¥#,##0`）」「列幅自動調整」を施した見栄えの良いExcelブック（2シート構成）を出力。

📊 出力レポート仕様
生成される monthly_sales_summary.xlsx は以下の2シートで構成されます。

統合データマスタ: 全拠点のデータを正規化し、日付昇順でソートした統合明細テーブル。

集計サマリー:

拠点 × カテゴリー別 売上マトリクス: 各拠点のカテゴリ別売上と総合計。

担当者別 実績集計表: 拠点ごとの各営業担当者の売上実績一覧。

🚀 クイックスタート
1. 必要ライブラリのインストール
pip install -r requirements.txt

2. テスト用ダミーデータの生成（動作確認用）
python main.py

※ 処理完了後、data/output/monthly_sales_summary.xlsx に装飾済み集計レポートが生成されます。
